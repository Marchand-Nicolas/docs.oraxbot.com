# Polls

import { Callout } from 'nextra/components'

Orax syncs polls across interserv groups. Discord uses native polls. Fluxer uses [`/poll`](/commands/poll). When a poll ends, votes from every mirrored copy are counted together and the combined results are posted.

## Discord (native polls)

Create a poll with Discord's built-in poll UI in a linked channel. Orax then:

1. Detects the poll on the message
2. Relays it to every other linked channel
3. Stores the question, answers, and expiry

On **other Discord channels**, members vote on a native Discord poll copy. On **Fluxer**, the poll is posted as text with numbered vote buttons. On **Telegram**, it is posted as text only (no voting).

<Callout type="info">
  There is no `/poll` slash command on Discord. Use Discord's native poll composer.
</Callout>

## Fluxer (`/poll`)

Fluxer has no native polls. Use [`/poll`](/commands/poll) in any Fluxer channel:

```
/poll "Best game?" "Chess" "Go" --duration 2h
```

That posts an **Orax Polls** panel with a vote menu. In a linked channel it is relayed to the rest of the group. Members vote with the menu or `/poll vote <id> <option number>`.

Default duration is **24 hours**. Options: **2–10**. Multiple answers are allowed unless you pass `--single`.

## Vote aggregation

When a poll expires (or is ended early on Fluxer):

1. A scheduler checks for due polls about every **15 seconds**
2. Orax reads vote counts from **all** Discord copies of the poll
3. Fluxer votes stored in the database are added to those totals
4. Combined results are posted in every linked channel as **Orax Polls**

<Callout type="info">
  People vote on separate copies (native Discord polls vs Fluxer buttons). The final tally is still one combined result.
</Callout>

## Example

If a poll is synced across 3 Discord servers:

- Server A: 10 votes for option 1, 5 votes for option 2
- Server B: 8 votes for option 1, 3 votes for option 2
- Server C: 2 votes for option 1, 7 votes for option 2

The aggregated result posted by Orax would be:

- Option 1: 20 votes
- Option 2: 15 votes

Fluxer votes for the same options are added on top of that.

## Limitations

- Results may take a few seconds after expiry (the aggregator runs on a short interval)
- Native Discord polls are tracked when they are sent in a **linked** channel
- Message mappings used to find copies last **30 days**
- If a webhook or channel is unavailable, votes from that copy may be missing
- Telegram shows the question and options as text and cannot collect votes
