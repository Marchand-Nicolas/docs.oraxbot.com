# /lock

import { Callout } from 'nextra/components'

Prevents non-admin users from sending messages in the interserv group. This is useful for temporary lockdowns during incidents or moderation.

## Usage

```
/lock
```

## Permissions

- **Moderator** — Group moderator (or Manage Messages if no custom list is set)
- Must be run in the **owner** server of the group

## What It Does

1. Enables the lock on the interserv group
2. Messages from guest servers are blocked
3. On the owner server, only **Administrators** can send; everyone else is blocked
4. Blocked messages are deleted and can be logged if a log channel is set

## Example

```
/lock
```

**Bot response:**
> ✅ Locked the group. Only admins of this server can send messages.

## Unlocking

To reverse the lock, use the [`/unlock`](/commands/unlock) command.

<Callout type="warning">
  Locking affects **all** channels in the group across all servers, not just the channel where the command was used.
</Callout>
