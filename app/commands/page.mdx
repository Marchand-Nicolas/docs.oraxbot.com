# Commands Overview

import { Callout } from 'nextra/components'

Orax uses Discord slash commands for all interactions. Commands are registered globally and available in any server where the bot is present. On Fluxer the same command names work as text commands.

## All Commands

| Command | Permission | Description |
|---|---|---|
| [`/create-interserv-group`](/commands/create-interserv-group) | Administrator | Create a new interserv group and get a join link |
| [`/link-channel`](/commands/link-channel) | Administrator | Link a channel to an existing interserv group |
| [`/unlink-channel`](/commands/unlink-channel) | Administrator | Unlink a channel from all interserv groups |
| [`/channel-infos`](/commands/channel-infos) | Everyone | View info about the group linked to the current channel |
| [`/debug-channel`](/commands/debug-channel) | Everyone | Run diagnostics on a text channel's webhook and permissions |
| [`/resync`](/commands/resync) | Administrator *(Orax Plus)* | Re-sync the last 30 messages if they weren't synchronized |
| [`/lock`](/commands/lock) | Moderator *(owner server)* | Prevent non-admins from sending messages in the group |
| [`/unlock`](/commands/unlock) | Moderator *(owner server)* | Reverse a lock, allowing messages again |
| [`/manage-group`](/commands/manage-group) | Moderator | Interactive button panel for group settings |
| [`/mute-user-from-interserv-group`](/commands/mute-user) | Moderator | Mute a user from the interserv group |
| [`/unmute-user-from-interserv-group`](/commands/unmute-user) | Moderator | Unmute a user from the interserv group |
| [`/track`](/commands/track) | Everyone | Trace a synced message to its original author and server |
| [`/rules`](/commands/rules) | Everyone | View the group's custom rules |
| [`/help`](/commands/help) | Everyone | Help text, links, and (for admins) language picker |
| [`/settings`](/commands/settings) | Everyone | Personal nickname and who can ping you |
| [`/giveaway`](/commands/giveaway) | Administrator or moderator | Create and manage giveaways |

<Callout type="info">
  **Moderator** permission means the user must be a group moderator (configured in group settings) or have **Manage Messages** permission in the server by default.
</Callout>

## Using Commands

On Discord, type `/` to search slash commands. On Fluxer, type the same command names as text (for example `/help`).

## Command Permissions

- **Administrator** — The user must have the Administrator permission in the Discord server
- **Moderator** — Group moderator, or Manage Messages if no custom moderator list is set. Server administrators always count
- **Everyone** — Any server member can use this command

Commands are shown to everyone in Discord. The bot enforces permissions in code.

Deprecated aliases: `/ban-user-from-interserv-group` and `/unban-user-from-interserv-group` still work but will be removed — use mute/unmute instead.

## Need Help?

If you're having trouble with commands, try the `/debug-channel` command to diagnose common issues. You can also visit our [support Discord server](https://discord.gg/e3pBtbum4A) for help.
