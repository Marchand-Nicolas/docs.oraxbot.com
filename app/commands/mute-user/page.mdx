# /mute-user-from-interserv-group

import { Callout } from 'nextra/components'

Mutes a user in the interserv group. The muted user's messages will no longer be relayed to other servers, and their messages in other servers won't appear in the current group's channels.

## Usage

```
/mute-user-from-interserv-group message_link:<link or user ID> [silent:true]
```

| Parameter | Type | Required | Description |
|---|---|---|---|
| `message_link` | String | Yes | Message link, or the author's user ID |
| `silent` | Boolean | No | If true, the user's messages stay visible locally but are not synced |

## Permissions

- **Moderator** — The user must be a group moderator or have Manage Messages permission

## What It Does

1. Resolves the user from a **message link** or **user ID**
2. The user is added to the group's mute list
3. Future messages from this user are blocked in all linked channels (or not relayed, if silent)
4. If a log channel is configured, the mute is logged

## Input Methods

| Method | Description |
|---|---|
| **Message link** | Right-click a synced message → Copy Message Link → paste it |
| **User ID** | The Discord user ID of the person to mute |

## Example

```
/mute-user-from-interserv-group message_link:https://discord.com/channels/123/456/789
```

**Bot response:**
> ✅ User muted in the group.

## Tracking Muted Users

Muted users are listed in the group's mute list on the [Orax Dashboard](https://oraxbot.com/dashboard) → Group Settings → Muted Users.

## Unmuting

To remove a mute, use the [`/unmute-user-from-interserv-group`](/commands/unmute-user) command.

<Callout type="info">
  Muting is per-group — a user muted in one interserv group can still participate in other groups. A **silent** mute leaves their messages visible in the origin channel but does not relay them.
</Callout>
